# What is SQL?

**What is SQL?**

- A language used to talk to databases.
- Each SQL command is called a **statement**.
- Examples here use **MySQL**. Other databases have small syntax changes.
- SQL is **not case-sensitive** (`SELECT` = `select`).
- A semicolon `;` marks the end of a statement.

**Main commands**

| Command | Job |
| --- | --- |
| SELECT | Get data |
| UNION | Join results of two or more SELECTs |
| INSERT | Add a new row |
| UPDATE | Change existing rows |
| DELETE | Remove rows |

---

**1. SELECT (get data)**

| Query | Meaning |
| --- | --- |
| `select * from users;` | Get **all columns** from the table `users` |
| `select username,password from users;` | Get only these two columns |
| `select * from users LIMIT 1;` | Get only the first row |
| `select * from users LIMIT 1,1;` | Skip 1 row, then return 1 row |
| `select * from users LIMIT 2,1;` | Skip 2 rows, then return 1 row |
- = all columns.
- In `LIMIT a,b`: **a = rows to skip**, **b = rows to return**.

**2. WHERE (pick exact data)**

| Query | Result |
| --- | --- |
| `where username='admin'` | Only rows where username is admin |
| `where username != 'admin'` | All rows except admin |
| `where username='admin' or username='jon'` | Rows matching **either** one |
| `where username='admin' and password='p4ssword'` | Rows matching **both** |

**3. LIKE (partial match)**

- `%` is a wildcard (means “any characters”).

| Query | Result |
| --- | --- |
| `like 'a%'` | Starts with **a** |
| `like '%n'` | Ends with **n** |
| `like '%mi%'` | Contains **mi** |

**4. UNION (combine results)**

- Joins results of two SELECT statements into one list.
- Rules:
    - Same **number of columns** in each SELECT.
    - Columns must have **similar data types**.
    - Columns must be in the **same order**.
- Example: join `customers` and `suppliers` to get one address list.`SELECT name,address,city,postcode from customers UNION SELECT company,address,city,postcode from suppliers;`

**5. INSERT (add data)**

- `insert into users (username,password) values ('bob','password123');`
- `into users` = which table.
- `(username,password)` = which columns.
- `values (...)` = the data for those columns.
- The `id` is added automatically (auto-increment).

**6. UPDATE (change data)**

- `update users SET username='root',password='pass123' where username='admin';`
- `SET` = which fields to change (separate with commas).
- `where` = which rows to change.

**7. DELETE (remove data)**

- `delete from users where username='martin';` removes only martin.
- `delete from users;` removes **all rows** (no WHERE).
- You can also use `LIMIT` to control how many rows are deleted.

**Key points**

- Always use **WHERE** with UPDATE and DELETE. Without it, **all rows** are changed or deleted.
- SELECT = read, INSERT = add, UPDATE = edit, DELETE = remove.
- UNION is very important for SQL injection later.
