# Intro

The **Domain Name System (DNS)** acts as the phonebook of the internet. It translates human-friendly domain names (like `tryhackme.com`) into machine-readable IP addresses (like `104.26.10.229`).
Every device connected to the internet has a unique **IP address**—a numerical label formatted as four sets of numbers ranging from 0 to 255 separated by periods (IPv4). Because remembering long sequences of numbers for every website is impractical, DNS automatically handles the lookup process in the background whenever you type a URL into your browser.
